# EconRadar

Every paper since 2020 from 20 leading economics journals and NBER working papers, summarised by a language model, tagged by field, method and data, and mapped as a network of strands and authors. It is a static, installable web app served by GitHub Pages at https://rfernex.github.io/EconRadar/radar/.

- `radar/`: the app, its configuration and its published data (model-written summaries only, no abstracts). See [radar/README.md](radar/README.md) for how the data are collected, summarised and published.
- `tools/`: the collector and the summarising tools, run on the maintainer's machine (see [tools/WEEKLY.md](tools/WEEKLY.md)).
- `shared/`: the motion styles the app shares with the maintainer's other pages.

The root page redirects to the app. Legal notice and privacy: https://rfernex.github.io/legal.html.
